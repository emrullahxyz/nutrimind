# docs/superpowers/plans/

Disiplinli plan yazımından çıkan uygulama planları buraya yazılır
(`YYYY-MM-DD-<konu>.md`; şablon: superpowers `writing-plans`).

**Yaşam döngüsü:** plan yazılır → yürütülür → **dosya bazında doğrulanır** (her adımın kanıtı:
dosya:satır) → başlığına "Durum" tablosu eklenir → `docs/archive/superpowers/`'e taşınır.

Bu klasörün boş görünmesi normaldir: **tamamlanmış plan burada tutulmaz.** Açık işler
`tasks/todo.md` → `## AÇIK İŞLER` bloğunda izlenir; arşivdeki planlar tarihsel kayıttır ve
(AGENTS.md madde 2 gereği) arşiv içeriği düzenlenmez.
